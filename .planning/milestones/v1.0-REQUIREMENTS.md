## Requirement Outcomes

**Validated as written — no requirement was reworded, weakened, or dropped mid-milestone.** All 24 shipped in the form they were defined on 2026-07-02.

Two notes on interpretation, both settled during execution and recorded here so the archive is not read against a different assumption later:

- **MODE-01** — the "dense overview" is the homepage itself (first-fold nav anchors plus CV button), not a separate `/overview` route. This was the Phase-2 reading and it held; the requirement text never demanded a distinct route.
- **WOW-01** — satisfied three times over. Phase 4 shipped the hero constellation; Phase 5 replaced it with a site-wide particle stage; Phase 6 replaced that with the KERN instanced-shard stage. The requirement's substance (one identity-bound signature moment, lazy, capability-gated, never in the initial bundle) holds at HEAD; the specific artifacts named in the Phase-4 documents no longer exist.

**Requirements re-verified after the phase 5/6 rewrites:** all of them. Because phases 5 and 6 replaced the visual and 3D layer *after* phases 3 and 4 were verified, the v1.0 milestone audit re-checked every requirement's wiring at HEAD rather than trusting the earlier reports. Result: 15/15 checked cross-phase exports wired, 0 orphaned, 0 missing, 6/6 E2E flows complete.

## Out of Scope (v1 decisions, preserved)

| Feature | Begründung |
|---------|------------|
| Blog / Schreib-Sektion | Keine etablierte Schreib-Routine — stale Blog schadet mehr als kein Blog |
| Sound-Design | Hohes Nerv-Risiko, geringer Hiring-Wert |
| npx CLI-Card & Easter Eggs (Konami, Console) | Vom Nutzer abgewählt; jederzeit günstig nachrüstbar |
| Testimonials | Vom Nutzer abgewählt für v1 |
| Meta-Case-Study ("How this site was built") | Vom Nutzer abgewählt; nach Launch jederzeit ergänzbar |
| `/uses`- und `/now`-Seiten | Pflege-Aufwand ohne Kern-Nutzen |
| Shader-Identity als Alternative | Durch Entscheidung für vollen Signature-3D-Moment ersetzt |
| Hosted CMS (Strapi/Contentful/Sanity) | Overkill für Single-Author; Git-basiertes Content-Modell ist das CMS |
| Skill-Prozentbalken | Bedeutungslose Zahlen, wirken unseriös auf Tech-Leads |
| Unskippbares Intro / erzwungener Preloader | Verletzt direkt den Core Value (Fakten in 30s) |
| Kommentare, Newsletter, Login, Besucherzähler | Kein Hiring-Wert, Moderations-/DSGVO-Last |
| Autoplay-Sound/-Video | Universell gehasst, Accessibility-Verstoß |
| Weiterverwendung des bestehenden Rewrites | Bewusster Neustart |
