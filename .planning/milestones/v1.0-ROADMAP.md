## Overview

Complete ground-up rebuild of Lasse Siemoneit's personal portfolio. The previous React/Vite/GSAP SPA was discarded outright; concept, design, content and stack were rethought from zero.

The delivery strategy was four vertical slices, each ending in a usable state: build the bilingual content model and a deployable foundation on lsiem.de first (content before effects — the answer to "thin content"), then ship the complete fast recruiter site to production (the counter to "a rebuild that never ships"), then establish the design direction and immersive scroll experience on clean animation infrastructure, then add the signature 3D moment as an architecturally removable layer. Two further phases replaced that 3D layer twice over as the visual ambition grew.

**Core value achieved:** a visitor says "wow" — and still finds who/what/contact in under 30 seconds if they're in a hurry.

## Milestone Summary

**Decimal Phases:** none — no urgent insertions were needed.

**Key Decisions:**

- **Roadmap**: coarse consolidation of 7 research phases into 4 vertical MVP slices (content foundation → recruiter site live → immersion → 3D + launch)
- **Roadmap**: live deploy to lsiem.de from Phase 1 onward (pipeline + CI budget), complete site live from end of Phase 2 — the antidote to "a rebuild that never ships"
- **Roadmap**: 3D moment as the last phase, architecturally removable (capability gate + lazy load + scroll bridge)
- **Stack**: Next.js 16 + React 19 + GSAP + Lenis + next-intl over the discarded Vite SPA — static-prerendered HTML gives good CWV despite heavy client animation
- **D-08**: exactly one animation engine (GSAP); no second engine admitted for the whole milestone
- **D-10**: reduced-motion is an unconditional zero-canvas gate — it beats even the `?webgl=force` override
- **D-11**: production is the calibrated source of truth for LCP, not local lab runs
- **Content**: Git-based content model as the CMS; no hosted CMS for a single author
- **DSGVO**: cookieless analytics, self-hosted fonts, zero third-party runtime calls — enforced by a build-time chunk tripwire

**Issues Resolved:**

- Thin-content risk — content model built and filled before any effects work
- Blank-shell LCP and weak SEO of the previous Vite SPA — replaced by SSG/SSR-first architecture
- `phase3-perf-bundle-gap` (~100KB apparent deployed-bundle overage) — traced to Vercel bot-mitigation script injection in datacenter Chrome, not hidden app code
- Silent no-mount on unknown-new GPUs (Apple M5 Pro and any post-snapshot GPU landing at detect-gpu `FALLBACK`) — fixed in 04-06, shipped in PR #21
- Unplanned "pure 3D canvas" rewrite with `navigator.webdriver` test evasion — caught in verification, deploy blocked, reverted
- ESLint toolchain breakage (eslint 10 vs eslint-plugin-react's `context.getFilename()`) — pinned to eslint 9
- Production LCP question — closed with real production traces roughly 3× under budget

**Issues Deferred:**

- Real external human tester for the 30-second stopwatch flow and reduced-motion walkthrough (SC 4)
- Physical mid-tier Android device measurement (SC 3) — needs hardware or a device lab
- AI-01 "Ask Lasse" RAG chat and AI-02 terminal easter egg — scoped to v1.x from the start
